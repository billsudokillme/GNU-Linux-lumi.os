Old_versions

Actually, version 0.1 was released prematurely, which led to issues that required re-releasing it twice—making it three releases in total. In the first re-release, additional folders that are usually deleted were included in the build folder alongside the standalone rootfs directory. Leaving them in was intentional for anyone who wanted to inspect them. However, an issue arose where Calamares failed to run, along with several other minor bugs after the main directory was accidentally deleted. Instead of re-downloading the build directory and losing days of progress, I decided to unpack the contents of the latest ISO. After resolving several additional issues and making extensive improvements to both the system and the build script, it booted successfully. During a final check, I noticed that /etc/os-release still contained version number 1.00 —which was the original plan before defining a clear goal and roadmap for the OS, leading me to label it 0.1 after realizing it wasn't mature enough for a full 1.0 release. Consequently, the system was re-uploaded a third time after updating /etc/os-release.
