Lumi, or "Li-mi" as I like to call it, is a Debian-based Linux system. Although it was not originally built directly on Debian, but rather assembled from tools, packages, and programs—mostly from Debian's KDE version, Debian itself, GNU tools, along with some of its own custom programs and modifications—I am not entirely sure about its classification: whether it is a hybrid of Debian, BusyBox tools, and other software, or simply a Debian-based system.

In any case, you can learn almost everything about the project at:
https://billsudokillme.github.io/GNU-Linux-lumi.os/doc/

Also, as of the time of writing, the project was founded, implemented, published, and documented by Youssef Ghouari.
